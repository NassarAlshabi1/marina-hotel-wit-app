## التوافق والموارد

- نقل إعداد أيقونات شريط التنقل الداكنة إلى موارد API 27+، مع شريط داكن واضح على API 26.
- حذف ثيمات وخلفيات Flutter غير المستخدمة، وتنظيف الموارد والصلاحيات غير المستخدمة. احتُفظ بصلاحية قراءة التخزين القديمة لأن خدمة النسخ المحلية ما زالت تستخدم مجلد Documents العام.
- استخدام أيقونة تكيفية واحدة انطلاقًا من الصورة الحالية، وإزالة نسخ الأيقونة الدائرية المكررة.
- تحويل أسماء قيم enum إلى النمط القياسي، مع إبقاء قيم JSON القديمة بواسطة `SerializedName` وقيم تفضيلات النسخ بواسطة `wireName`، واختبار القراءة القديمة.
- تحديد Locale صراحةً لتنسيق حجم النسخ وتمثيل البيانات الست عشريًا، مع الحفاظ على أسماء الوحدات العربية.
- نقل نصوص تشخيص الإقلاع إلى موارد debug، دون إدراجها في نسخة الإصدار.
- حذف متغيرات وخصائص ومعاملات غير مستخدمة؛ الاستدعاء الذي يصلح البيانات بعد الاستعادة بقي موجودًا ولم يُحذف مع متغير النتيجة غير المستخدم.
