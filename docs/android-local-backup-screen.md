# شاشة النسخ الاحتياطي المحلي والاستعادة

- المسار: الإعدادات ← الصيانة ← النسخ الاحتياطي المحلي والاستعادة (`local_backup`).
- زر النسخ الاحتياطي في مركز الصيانة يفتح الشاشة نفسها؛ الدخول الجديد مقيد بالمدير.
- لا تنشئ الشاشة `CloudflareD1ViewModel`، ولا تتطلب المرور بالتبويب السحابي. تبقى شاشة النسخ الشاملة السابقة متاحة.
- تعيد استخدام إنشاء JSON.gz، منتقي الملفات، قائمة النسخ، المشاركة، تأكيد الاستعادة والحذف، وتصدير Excel الموجودة مسبقاً.
- استيراد ملف يضيفه للقائمة؛ الاستعادة إجراء منفصل. Excel ونسخ حقول الصيانة ليست نسخ بيانات للاستعادة؛ SQLite الخام يبقى مرفوضاً ويُعطّل خيار استعادته بالقائمة.
- رفض JSON الخالي من أي جدول معروف قبل الاستيراد إلى القاعدة يمنع اعتبار تقارير الصيانة عملية استعادة ناجحة. اختبار انحدار يغطي أربع حاويات غير صالحة ويحفظ بيانات الحجز والغرفة.
- تعطيل خيارات القائمة والتأكيد والتحديث أثناء العمل. الشاشة المستقلة تمنع الرجوع العادي أثناء العملية؛ ليست خدمة خلفية ولا ضماناً ضد إنهاء العملية بواسطة النظام.
- التحذير يوضح استبدال الجداول المضمنة ثم تشغيل معالجة ما بعد الاستعادة الحالية. الاستيراد والمعالجة ليسا معاملة واحدة؛ لم تتغير الحسابات المالية أو عقود المزامنة.
- النسخة عقد جداول JSON، وليست صورة SQLite كاملة. المسار الحالي يحمّل JSON في الذاكرة؛ لا يوجد إثبات جديد لاستعادة ملفات ضخمة على RAM بسعة 1GB.

## التحقق

`git diff --check` ناجح. أضيف اختبار انحدار إلى `RestoreFixServiceTest`؛ يحتاج التنفيذ في CI لغياب Java/Android SDK محلياً. فحص الواجهة ومنتقي الملفات والمشاركة على جهاز فعلي ما زال مطلوباً.
