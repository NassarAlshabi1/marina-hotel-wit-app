## 🔧 حل التعارضات

### ماذا يحدث إذا عدّل جهازان نفس النزيل؟

النظام يستخدم **Last Write Wins** (آخر كتابة تفوز):

```
الهاتف 1: يعدّل رقم هاتف "أحمد" إلى 0500000001 (10:00 AM)
الهاتف 2: يعدّل رقم هاتف "أحمد" إلى 0500000002 (10:05 AM)

المزامنة:
1. الهاتف 1 يرفع التعديل (10:00 AM) إلى MongoDB
2. الهاتف 2 يرفع التعديل (10:05 AM) إلى MongoDB
3. MongoDB يحفظ التعديل الأحدث (10:05 AM)
4. عند المزامنة التالية:
   - الهاتف 1 يجلب التعديل (10:05 AM)
   - ✅ الرقم أصبح 0500000002 على الجهازين
```

## ⚙️ الإعدادات المتقدمة

### تغيير فترة المزامنة في الكود

في ملف `flutter_mongo_sync_service.dart`:

```dart
// من:
void startAutoSync({Duration interval = const Duration(minutes: 1)})

// إلى (مثلاً كل 30 ثانية):
void startAutoSync({Duration interval = const Duration(seconds: 30)})
```

### تفعيل المزامنة عند فتح التطبيق

في ملف `main.dart`:

```dart
class _MyAppState extends State<MyApp> {
  @override
  void initState() {
    super.initState();
    _initializeAutoSync();
  }

  Future<void> _initializeAutoSync() async {
    final storage = const FlutterSecureStorage();
    final password = await storage.read(key: 'mongodb_password');
    
    if (password != null) {
      final syncService = FlutterMongoSyncService.getInstance(/* db */);
      await syncService.initialize(password);
      syncService.startAutoSync();
    }
  }
}
```

## 🐛 استكشاف الأخطاء

### 1. خطأ: "Failed to connect to MongoDB"
**الأسباب المحتملة:**
- كلمة مرور خاطئة
- لا يوجد اتصال بالإنترنت
- MongoDB Cluster معطل

**الحل:**
1. تحقق من كلمة المرور
2. تحقق من الإنترنت
3. افتح [MongoDB Atlas](https://cloud.mongodb.com/) وتأكد أن Cluster يعمل

### 2. المزامنة لا تعمل
**الأسباب المحتملة:**
- المزامنة التلقائية غير مفعلة
- التطبيق في الخلفية (قد يُوقف Android/iOS العمليات)

**الحل:**
1. فعّل المزامنة التلقائية
2. استخدم "مزامنة الآن" يدوياً
3. احفظ التطبيق مفتوحاً

### 3. البيانات لا تظهر على الجهاز الآخر
**الأسباب المحتملة:**
- لم تحدث المزامنة بعد (انتظر الفترة المحددة)
- الجهاز الآخر غير متصل

**الحل:**
1. انتظر الفترة المحددة (1 دقيقة افتراضياً)
2. أو اضغط "مزامنة الآن" على الجهازين
3. تحقق من الإحصائيات
