## أنواع التخفيض

### 1️⃣ تخفيض إجمالي (`total`)
**الوصف:** يُطرح التخفيض من الإجمالي النهائي بعد حساب جميع الليالي

**مثال:**
```
سعر الغرفة: 6,000 ريال/ليلة
عدد الليالي: 8
التخفيض: 1,000 ريال

الحساب:
- الإجمالي قبل التخفيض: 6,000 × 8 = 48,000
- الإجمالي بعد التخفيض: 48,000 - 1,000 = 47,000 ✓
```

**الاستخدام:**
- التخفيضات الموحدة
- عروض ترويجية ثابتة
- خصومات إدارية

---

### 2️⃣ تخفيض لكل ليلة (`per_night`)
**الوصف:** يُطرح التخفيض من سعر كل ليلة بدءاً من تاريخ معين

**مثال 1 - بدون تاريخ بداية:**
```
سعر الغرفة: 15,000 ريال/ليلة
عدد الليالي: 5
التخفيض: 1,000 ريال/ليلة

الحساب:
- السعر المخفض: 15,000 - 1,000 = 14,000 ريال/ليلة
- الإجمالي: 14,000 × 5 = 70,000 ريال ✓
```

**مثال 2 - مع تاريخ بداية:**
```
تاريخ الدخول: 12-1-2020
سعر الغرفة: 15,000 ريال/ليلة
التخفيض: 1,000 ريال/ليلة
تاريخ بدء التخفيض: 13-1-2020

الحساب:
- ليلة 12-1 إلى 13-1: 15,000 × 1 = 15,000 ريال (بدون تخفيض)
- الليالي من 13-1 وما بعد: (15,000 - 1,000) × 4 = 56,000 ريال
- الإجمالي: 15,000 + 56,000 = 71,000 ريال ✓
```

**الاستخدام:**
- التخفيضات التدريجية
- عروض للإقامات الطويلة
- تخفيضات موسمية تبدأ من تاريخ معين

   - يمكنك اختيار تاريخ بدء التخفيض (اختياري)
   - إذا تركته فارغاً، سيطبق على جميع الليالي

## الحسابات في الخلفية

### الكود الجديد:
```dart
if (discountType == 'total') {
  // تخفيض إجمالي
  final subtotal = nightlyRate * totalNights;
  totalDue = (subtotal - discount).clamp(0.0, subtotal);
} else {
  // تخفيض لكل ليلة
  if (discountStartDate != null) {
    // حساب الليالي قبل وبعد التخفيض
    for (final segment in segments) {
      if (segmentDate.isBefore(discountDate)) {
        nightsBeforeDiscount++;
      } else {
        nightsWithDiscount++;
      }
    }
  } else {
    nightsWithDiscount = totalNights;
  }
  
  final fullPriceTotal = nightlyRate * nightsBeforeDiscount;
  final discountedRate = (nightlyRate - discount).clamp(0.0, nightlyRate);
  final discountedTotal = discountedRate * nightsWithDiscount;
  totalDue = fullPriceTotal + discountedTotal;
}
```

## اختبار النظام

### مثال اختبار:
1. أنشئ حجز جديد
2. سعر الغرفة: 10,000 ريال
3. الليالي: 3
4. التخفيض: 500 ريال

**تخفيض إجمالي:**
- الإجمالي: (10,000 × 3) - 500 = 29,500 ريال ✓

**تخفيض لكل ليلة:**
- الإجمالي: (10,000 - 500) × 3 = 28,500 ريال ✓
