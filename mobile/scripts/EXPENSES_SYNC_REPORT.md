## ⚠️ ملاحظات مهمة

### 1. ✅ حقول مُضافة حديثاً (2026-06-27) — تم حلها:

الحقول التالية كانت موجودة على Appwrite Cloud لكن **لم تكن مُدرجة** في
`validFieldsPerCollection['expenses']`:
- `employeeUuid` — UUID الموظف للربط عبر الأجهزة (يُضاف في `_processExpenseEntry` لمصروفات الرواتب)
- `syncTimestamp` — طابع زمني للمزامنة
- `id` — معرف (optional)

### 2. تحديث `_expenseToRemote()`

تم تعديل `_expenseToRemote()` لإرسال بنشاط:
- `sync_origin = expense.origin`
- `syncTimestamp = expense.lastModified`

### 3. تحويل النوع

- `amount` على Cloud هو `integer`، محلياً `double` — يتم التحويل عبر `.round()`

### 4. ربط الموظفين

- `relatedId` يربط المصروف بالموظف محلياً (FK)
- `employeeUuid` يُضاف للرواتب فقط لربط الموظف عبر الأجهزة المختلفة
