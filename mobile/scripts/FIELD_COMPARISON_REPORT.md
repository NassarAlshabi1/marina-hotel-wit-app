## 🔧 SyncFields Mixin (الحقول المشتركة)

```dart
mixin SyncFields on Table {
  TextColumn get localUuid      // UUID فريد محلياً
  IntColumn get serverId        // معرف السيرفر (nullable)
  IntColumn get createdAt       // تاريخ الإنشاء (epoch)
  IntColumn get updatedAt       // تاريخ التحديث (epoch)
  IntColumn get deletedAt      // تاريخ الحذف الناعم (nullable)
  IntColumn get lastModified   // آخر تعديل (epoch)
  TextColumn get createdAtIso  // تاريخ ISO
  TextColumn get updatedAtIso  // تاريخ ISO
  TextColumn get deletedAtIso  // تاريخ ISO
  IntColumn get createdAtEpoch // epoch
  IntColumn get lastModifiedEpoch // epoch
  IntColumn get version        // رقم الإصدار
  TextColumn get origin        // 'local' أو 'server'
  TextColumn get vectorClock   // ساعة المتجهات (JSON)
  TextColumn get deviceId      // معرف الجهاز
}
```

## ⚠️ ملاحظات مهمة

### 1. Collections لم تُفحص من Cloud
معظم الجداول (15 من 19) تم تحليلها من الكود فقط، ولم يتم التحقق من تطابقها مع Appwrite Cloud.

### 2. الصلاحيات
بعض الـ Collections تحتاج صلاحيات إضافية في Appwrite Console:
- `employees` - **401 Unauthorized**
- `expenses` - **401 Unauthorized**
- `salary_withdrawals` - **401 Unauthorized**

### 3. الحقول الإضافية في Cloud
الحقول التالية موجودة في Appwrite Cloud فقط:
- `sync_origin` - أصل المزامنة
- `syncTimestamp` - طابع زمني للمزامنة
- `sync_version` - إصدار المزامنة
- `sync_vector_clock` - ساعة المتجهات

## ✅ التوصيات

### 1. التحقق من Cloud
للجداول التي لم تُفحص من Cloud، يجب:
1. إضافة الصلاحيات في Appwrite Console
2. تشغيل سكريبت التحقق
