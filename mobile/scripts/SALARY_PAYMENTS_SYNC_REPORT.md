## ⚠️ ملاحظات مهمة

### 1. ✅ حقول مُضافة حديثاً (2026-06-27):

- `amount` — المبلغ (كان مفقوداً!)
- `sync_origin` — مصدر المزامنة
- `id` — معرف
- `deleted_at`, `vector_clock`, `device_id`, `sync_timestamp`, `last_modified` — Legacy snake_case

### 2. ❌ حقول محذوفة (2026-06-27):

- `notes` — غير موجود على Cloud
- `paymentDate` — غير موجود على Cloud (استخدم `paymentDateIso`)
- `employeeId` — غير موجود على Cloud (يُربط عبر `cycleId` → `salary_cycles`)
- `sync_version` — استخدم `version` بدلاً منها
- `sync_vector_clock` — استخدم `vectorClock` بدلاً منها

### 3. ملاحظات عامة

- جدول `salary_payments` يُستخدم لتسجيل **دفعات الرواتب**
- مرتبط بجدول `salary_cycles` عبر `cycleId`
- `paymentDateIso` هو تاريخ الدفع بصيغة ISO
- `method` طريقة الدفع (مثل: "نقدي", "تحويل بنكي")
- `amount` على Cloud هو `integer`
