## 🧮 حاسبة سريعة

### لحساب النتيجة المتوقعة يدوياً:

```python
# بايثون
from datetime import datetime, timedelta

def calculate_expected_nights(checkin_str, restore_date_str):
    checkin = datetime.fromisoformat(checkin_str)
    restore = datetime.fromisoformat(restore_date_str)
    
    # حساب الأيام الكاملة
    days = (restore.date() - checkin.date()).days
    if days == 0:
        days = 1
    
    # قاعدة الساعة 14:00
    if restore.hour > 14 or (restore.hour == 14 and restore.minute > 0):
        days += 1
    
    return days

# مثال
checkin = "2025-01-10T10:00:00"
restore = "2025-01-13T15:00:00"
nights = calculate_expected_nights(checkin, restore)
print(f"الليالي: {nights}")  # النتيجة: 4 ليالي
```
