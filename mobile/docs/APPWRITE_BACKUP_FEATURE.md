# ميزة النسخ الاحتياطي الشامل (Appwrite Backup)

توفر هذه الميزة إمكانية إنشاء نسخة احتياطية محلية شاملة لجميع بيانات التطبيق بتنسيق JSON، واستعادتها ورفعها مباشرة إلى خادم Appwrite.

## المكونات الرئيسية

### 1. `ComprehensiveAppwriteBackupService`
موجود في `mobile/lib/services/comprehensive_appwrite_backup_service.dart`.
هذه الخدمة مسؤولة عن:
- قراءة جميع الجداول من قاعدة البيانات المحلية (Drift).
- تحويل البيانات إلى تنسيق JSON موحد.
- حفظ الملف محلياً للمشاركة أو التخزين.
- قراءة ملفات JSON المحفوظة سابقاً.
- رفع البيانات إلى Appwrite مع معالجة التضارب (إنشاء جديد أو تحديث).

### 2. `ComprehensiveBackupScreen`
موجود في `mobile/lib/screens/settings/comprehensive_backup_screen.dart`.
واجهة المستخدم التي تتيح:
- زر "تصدير نسخة محلية": ينشئ ملف JSON ويحفظه أو يشاركه.
- زر "رفع نسخة إلى Appwrite": يطلب من المستخدم اختيار ملف JSON، ثم يرفعه إلى الخادم.
- عرض حالة التقدم أثناء العمليات الطويلة.

## كيفية الاستخدام

1. انتقل إلى **الإعدادات** -> **إعدادات مزامنة Appwrite**.
2. انقر على زر **النسخ الاحتياطي الشامل والاستعادة** (باللون البنفسجي).
3. **للتصدير**: اضغط على "تصدير نسخة محلية"، وسيتم إنشاء الملف وعرض خيار مشاركته.
4. **للاستعادة/الرفع**: اضغط على "رفع نسخة إلى Appwrite"، اختر الملف من الهاتف، ووافق على التأكيد.

## ملاحظات تقنية

- **التعامل مع البيانات**: يتم تنظيف البيانات قبل الرفع (إزالة الحقول الخاصة بالنظام مثل `$id`, `$createdAt` إلا إذا كانت مطلوبة للتطابق).
- **الهوية**: يتم استخدام `localUuid` أو `$id` لضمان تطابق المستندات بين المحلي والخادم.
- **التحديث**: إذا كان المستند موجوداً بالفعل (Conflict 409)، تقوم الخدمة بتحديثه بالبيانات الموجودة في الملف، مما يضمن أن النسخة المرفوعة هي الأحدث.

## متطلبات التشغيل
- يحتاج التطبيق إلى صلاحيات تخزين لقراءة/كتابة الملفات.
- يجب تهيئة اتصال Appwrite مسبقاً (Endpoint, Project ID).
