## 🎯 النتائج المتوقعة

### للحجوزات النشطة (actualCheckout = null):

```
✅ الليالي = nightsWithCutoff(checkinDate, checkout: DateTime.now())
✅ المبلغ المتوقع = الليالي × سعر الغرفة
✅ تحذير إذا: المدفوع < المتوقع
✅ سجل في restore_fix_log
```

### للحجوزات المكتملة (actualCheckout != null):

```
✅ الليالي = nightsWithCutoff(checkinDate, checkout: actualCheckout)
✅ لا تتغير بعد الاستعادة
✅ لا سجل في restore_fix_log (إلا إذا كان هناك خطأ)
```

## 🐛 استكشاف الأخطاء الشائعة

### الخطأ 1: "FormatException: Invalid date format"

**السبب**: تاريخ فاسد في قاعدة البيانات  
**الحل**: تحقق من صيغة التواريخ (يجب أن تكون ISO 8601)

```dart
// صحيح ✅
"2025-01-13T10:30:00.000"

// خاطئ ❌
"13/01/2025"
"2025-1-13"
```

### الخطأ 2: "actualCheckout is null"

**السبب**: هذا ليس خطأ! الحجز نشط  
**التوضيح**: الحجوزات النشطة لا تحتوي على actualCheckout

### الخطأ 3: الليالي لم تتحدث

**الأسباب المحتملة:**
```
1. الحجز ليس نشطاً (status != checked_in/محجوزة)
2. يوجد actualCheckout (الحجز مكتمل)
3. الليالي صحيحة بالفعل (لا حاجة للتحديث)
```

**التحقق:**
```dart
// في console logs، ابحث عن:
"🔍 العثور على X حجز يحتاج إلى إصلاح"

// إذا كانت X = 0، فلا توجد حجوزات تحتاج إصلاح
```
