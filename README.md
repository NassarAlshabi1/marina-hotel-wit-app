# Marina Hotel

مستودع نظام إدارة الفندق. يضم تطبيق Flutter، وواجهة PHP/API، وأدوات ومراجع تشغيلية.

## البنية

- `mobile/` — تطبيق Flutter والمزامنة والاختبارات.
- `admin/`, `api/`, `includes/` — الواجهة وواجهات PHP الحالية.
- `docs/guides/` — أدلة الإعداد والتشغيل.
- `docs/reports/` — تقارير التدقيق والإصلاحات والمراجعات.
- `scripts/` — أدوات الصيانة والتشخيص؛ راجع [فهرس أدوات PHP](scripts/php/README.md).
